# 使用说明

## 1. 启动

开发环境启动：

```powershell
python main.py
```

打包后启动：

```powershell
dist\TGArchiveManager\TGArchiveManager.exe
```

首次启动会初始化配置目录、日志目录、SQLite 数据库、session 目录、下载目录和导出目录。

## 2. 通用下拉框

选择搜索工具、聊天、目标群、任务、消息类型或日志文件时，可以直接展开下拉框查看全部选项；也可以先在下拉框输入关键字，候选列表会只显示模糊匹配结果。按回车会选择当前首个匹配项；没有输入关键字时，下拉框仍显示全部结果。

## 3. 设置

进入“设置”页后可以编辑 Telegram、搜索、转发、备份下载、导出和日志配置。点击“保存配置”会写入本机 `config/config.yaml`，不会修改 `config/config.yaml.example`。

下载配置中的图片、视频、文件、音频开关，最大文件大小、失败重试和跳过已存在文件会影响后续媒体下载任务。转发配置中的单任务最大条数会限制搜索结果卡片转发和聊天记录转发。

Bot 公开搜索、TG 频道搜索、搜索结果媒体下载、转发管理和备份下载页的运行中任务可点击“取消任务”或“取消下载”。取消是协作式停止：当前安全步骤结束后退出，已完成并入库的记录会保留，未处理条目不会被记为失败。

## 4. Telegram 登录

1. 打开“账号登录”页。
2. 输入 `API ID`、`API Hash` 和手机号。
3. 点击发送验证码。
4. 输入 Telegram 收到的验证码。
5. 如果账号启用了二步验证，输入二步验证密码。
6. 登录成功后 session 保存在 `sessions` 目录，下次启动会自动恢复。

日志会脱敏 `api_hash`、验证码和密码。

## 5. 聊天列表

1. 登录后进入“聊天列表”页。
2. 同步账号可访问的聊天；如果 Telegram 官方客户端已配置聊天文件夹/分组，同步时会一并读取并显示在“官方分组”列。
3. 可按名称、username、本地标签或官方分组过滤聊天。
4. 可编辑本地标签，用于后续选择备份源或整理目标。
5. 可勾选本地聊天记录并删除；删除只移除软件本地聊天记录和对应自建群登记，不会退出或删除 Telegram 远端聊天。

## 6. Bot 公开搜索

1. 进入“Bot 公开搜索”页。
2. 输入关键词。
3. 选择搜索工具：已配置/已同步的 Bot，或自定义 Bot。
4. 点击开始搜索。
5. 保存的结果会写入 `public_search_tasks` 和 `public_search_results`。

如果 Bot 要求人机验证，界面会显示软件获取到的验证内容，用户在软件内手动选择后提交。

Bot 搜索结果可在页面中预览为转发卡片，也可删除选中的本地搜索结果。
如果结果文本、Bot 按钮或链接预览中包含 `telegra.ph`，软件会显示为“Telegraph 图片页面卡片”，并解析页面标题、发布时间、作者/来源、图片数量和正文中的 Telegram 跳转链接。下载选中媒体时，“Telegraph 图片下载数”为 `全部` 表示下载页面内全部图片，也可以输入指定数量只下载前 N 张。
Bot 分页搜索会按搜索工具配置中的分页间隔控制点击下一页按钮的节奏。

## 7. TG 频道搜索

1. 先在“聊天列表”页同步当前账号可访问的聊天。
2. 进入“TG 频道搜索”页。
3. 在左侧“搜索范围”中按官方分组筛选并勾选一个或多个频道/群聊；分组可折叠，勾选分组可批量选择或取消组内频道。
4. 输入关键词和最大结果数。
5. 点击开始搜索。
6. 保存的结果会写入 `public_search_tasks` 和 `public_search_results`，并且只来自已勾选的频道/群聊。

TG 频道搜索不使用 Bot，只搜索当前账号已加入且可访问的频道和群聊。搜索结果表格和转发卡片会显示媒体大小；Telegraph 页面卡片会显示图片数量。带媒体且有原消息定位信息的结果可直接下载，下载进度会显示当前第几个任务、已下载 MB 和图片张数。
如果搜索到的 Telegram 消息或链接预览指向 `telegra.ph`，结果会作为 Telegraph 图片页面卡片保存和下载，不会按 Telegram 原生图片/视频媒体处理。

## 8. 搜索结果

“搜索结果”页用于统一管理已经保存到 SQLite 的 Bot 搜索和 TG 频道搜索结果。

1. 可按搜索任务、关键词、类型、时间范围和最大条数筛选。
2. 可勾选结果并预览为纯文本转发卡片。
3. 可下载勾选结果关联的媒体或 Telegraph 图片页面。
4. 可删除勾选结果，或选择具体任务后删除当前搜索任务及其全部结果。

删除搜索结果或搜索任务只清理本地 SQLite 结果、Telegraph 明细和直接关联的转发元数据，不会删除 Telegram 远端内容，也不会删除下载目录中已存在的媒体文件。

## 9. 转发管理

1. 进入“转发管理”页。
2. 从已保存的公开搜索结果中筛选并勾选条目。
3. 选择已有目标群，或创建整理群。
4. 使用预览确认卡片文本。
5. 开始转发。

默认发送间隔是 3 秒。当前只发送文本卡片，不强制转发原始消息。转发页也可删除勾选的本地搜索结果。
如果勾选数量超过设置中的“单任务最大条数”，转发任务不会启动。

## 10. 备份下载

1. 进入“备份下载”页。
2. 选择聊天。
3. 设置最近 N 条、时间范围、是否增量备份。
4. 点击“预览最近消息”，先把指定范围内的聊天内容保存到本地列表用于预览。
5. 在消息列表中查看类型（文字、链接、图片、视频、文件、Telegraph 图片页面卡片等）；有 `file_size` 的图片、视频、文件、音频和普通媒体会显示大小，Telegraph 页面会显示已解析的图片数量，未解析时显示“图片数未知”。
6. 勾选需要下载的消息，可使用“预览勾选”确认内容。
7. 点击“下载勾选媒体”，下载已勾选且账号可访问消息中的媒体；下载中会显示当前第几个任务、已下载 MB、当前文件进度和图片张数。
8. 可点击“删除勾选记录”清理本地消息记录及文件/下载/转发元数据；不会删除已下载到磁盘的媒体文件，也不会删除 Telegram 远端消息。

“增量备份”会尽量只拉取上次备份游标之后的新消息；如果本地该聊天缓存数量少于本次设置的最近 N 条，软件会自动回补最近 N 条，避免只预览到少量新消息。包含 `telegra.ph` 的备份消息会显示为“Telegraph 图片页面卡片”，下载勾选媒体时可通过“Telegraph 图片下载数”限制下载前 N 张图片，`全部` 表示下载页面内全部图片。
下载勾选媒体会遵守设置页中的媒体类型开关、最大文件大小和跳过已存在文件配置；被策略跳过的条目会记录为 skipped。

聊天记录转发：

1. 在消息列表中勾选需要转发的本地聊天记录。
2. 点击“预览勾选”查看实际将发送的纯文本记录。
3. 在“聊天记录转发”区域选择已有目标群，或选择“自动新建一个群组”并可填写新群名。
4. 点击“转发勾选记录”。如果勾选内容和最近预览不一致，软件会先重新生成预览，需要再次点击确认发送。

当前聊天记录转发发送的是纯文本记录，包含来源 `chat_id/message_id`、时间、发送者、内容、媒体文件名/大小和原始链接；图片和视频会额外输出 `tgarchive://download?...` 内部下载链接。后续如果把目标群的这些文本记录备份回软件，勾选后点击“下载勾选媒体”，软件会按内部下载链接定位原始媒体并下载。不会绕过 Telegram 权限强制转发原始消息或媒体。

## 11. 本地搜索和导出

本地搜索支持按关键词、聊天、时间和消息类型过滤 SQLite 中已备份的消息。搜索结果可勾选后删除，删除语义与“备份下载”页的本地消息删除一致。

导出页支持：

- CSV
- Excel
- JSON
- HTML，可选增强

导出文件默认写入 `exports`。

## 12. 日志排查

进入“日志”页后可以按以下条件过滤：

- 日志文件
- 模块
- 等级
- 任务 ID
- 关键词或错误码

可执行操作：

- 打开日志目录
- 导出当前筛选日志
- 复制最新错误详情

任务独立日志位于 `logs/tasks`。
日志保留天数和公开搜索/转发/下载独立日志开关可在“设置”页调整；关闭独立日志后，相关日志仍会进入应用主日志。
